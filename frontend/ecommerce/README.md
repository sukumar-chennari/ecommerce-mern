# 🎨 Ecommerce Frontend - Premium Storefront

A modern, responsive, and high-performance React application built for a premium shopping experience.

## ✨ Highlights
- **Performance Optimized**: Built with Vite and RTK Query for lightning-fast loads.
- **State Management**: Redux Toolkit (RTK) for predictable UI state.
- **Server State**: Automated caching and refetching with RTK Query.
- **Responsive Design**: Utility-first styling with Tailwind CSS.
- **Real-time UX**: Instant notification toasts via Socket.io.

## 🛠 Tech Stack
- **Framework**: React 18 (TypeScript)
- **State/API**: Redux Toolkit & RTK Query
- **Styling**: Tailwind CSS
- **Routing**: React Router 6
- **Icons**: Lucide React / HeroIcons

## 🚦 Installation

1. `npm install`
2. Configure `.env`
3. `npm run dev`
